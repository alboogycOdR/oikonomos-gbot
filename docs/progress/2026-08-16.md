### E3 — Governance core ⚑ (complete, adversarially reviewed)

- `packages/policy` — risk-tier resolution (100% branch coverage), role constraints (rate limits, domains)

- `packages/broker` — PreToolUse endpoint (all three Handover §4.1 response shapes), idempotency per `toolUseId`, fail-closed on timeout/500/malformed body, capability kill switch

The broker task took **four review rounds**, every rejection the same defect class: correct code, untested guard. Final state — replay cache correctly scoped to tenant+role+toolUseId (an earlier round had a live cross-tenant authorisation bypass, closed and proven by mutation), LRU-bounded with a liveness assertion, in-flight decisions provably immune to eviction-induced split-brain, ADR-003's ceiling-vs-floor trap defended by a distinct type rather than a comment. Ten mutation probes, all bite.

### Outside the WBS — ahead of schedule
**OpenSandbox** (E5's replacement per ADR-006, superseding hand-built Docker isolation) deployed on clawsrv: Docker backend, Tailscale-bound, pinned images (R14), `network_mode=bridge` (the upstream default of `host` would have placed every sandbox in the host's own network namespace, alongside ~25 live production services). Tailscale-only verified by **observed refusal** from public IPv4, public IPv6 and loopback — not by reading config. End-to-end lifecycle (create → TTL reap → delete) verified.

One gap deliberately deferred, not overlooked: sandbox port publishes (`0.0.0.0`, no bind-address option in OpenSandbox) currently rely on an upstream Hetzner firewall this host does not own or control — `ufw`'s default-deny does **not** cover Docker-published ports (they traverse `FORWARD` via NAT, never `INPUT`). Tracked as **TASK-027**, do-not-dispatch, triggered to fire before OIK-043 puts a real workload in a sandbox.
